Coding guide

The basics you need to start writing scripts in Unity.

Basics

Every Unity script looks like this. Your code goes inside the class.

using UnityEngine;

public class Player : MonoBehaviour
{
    void Start()
    {

    }

    void Update()
    {

    }
}
  • Start runs once when the game starts
  • Update runs every frame
  • The class name has to match the file name
  • Every line ends with ;

Variables

A variable holds a value. Put them at the top of your class.

TypeHoldsExample
booltrue or falsebool isAlive = true;
intwhole numbersint coins = 10;
floatdecimalsfloat speed = 5.5f;
doublebig decimalsdouble money = 1000.75;
stringtextstring playerName = "Myers";
enuma list of optionsGameMode mode = GameMode.Infection;

Make a variable public or add [SerializeField] to see it in the inspector. Private ones and ones with no word in front are hidden.

public float jumpPower = 10f;
[SerializeField] private int health = 100;
bool isHidden;

Bools

The easiest one. It's either true or false.

public bool canJump = true;
bool isDead;

void Start()
{
    canJump = false;
    isDead = true;
}

Flip it with !

isPaused = !isPaused;

Ints

Whole numbers. You can add, subtract, multiply and divide them.

public int coins = 0;

coins++;
coins--;
coins += 10;
coins -= 10;
coins *= 2;
coins /= 2;

++ and -- change it by 1. += and -= change it by any number you want.

Floats

Like ints but with decimals. Always put an f at the end or you'll get an error.

public float speed = 1.5f;

speed++;
speed--;
speed += 5.5f;
speed -= 5.5f;
speed *= Time.deltaTime;

Doubles

A float with more precision. No f needed, but it uses more memory. Unity mostly uses floats, so you won't need these much.

public double money = 1.5;

money += 1.3;
money -= 1.3;

Strings

Text. Always in quotes.

public string playerName = "Myers";

playerName += "123";

if (string.IsNullOrEmpty(playerName))
{
    Debug.Log("No name set");
}

playerName = playerName.Substring(0, playerName.Length - 1);

int letters = playerName.Length;
string upper = playerName.ToUpper();

Substring here cuts off the last letter. Change the 1 to cut off more. You have to set the string to the result or nothing changes.

Enums

A list of options you pick from. Great for game modes, states and menus.

public enum GameMode
{
    Casual,
    Infection,
    Competitive
}

public GameMode mode = GameMode.Casual;

You can give each option a number if you want. If you don't, they go 0, 1, 2 on their own.

public enum Rank
{
    Bronze = 0,
    Silver = 1,
    Gold = 2
}

Use a switch to do different things for each option.

switch (mode)
{
    case GameMode.Casual:
        Debug.Log("Casual");
        break;
    case GameMode.Infection:
        Debug.Log("Infection");
        break;
}

Voids

A void is a block of code you can run whenever you want. You call it by its name.

void Jump()
{
    rb.AddForce(Vector3.up * jumpPower);
}

void Update()
{
    if (Input.GetKeyDown(KeyCode.Space))
    {
        Jump();
    }
}
TypeWho can use it
voidonly this script (same as private)
private voidonly this script
public voidany script, and buttons/events in the inspector
protected voidthis script and scripts that inherit from it
static voidno object needed, call it with the class name
public void TakeDamage(int amount)
{
    health -= amount;
}

public static void ResetScore()
{
    GameManager.score = 0;
}

Other scripts call them like this:

player.TakeDamage(10);
GameManager.ResetScore();

If you want a void to give something back, swap void for the type.

int GetCoins()
{
    return coins;
}

Private voids

Only the script it's in can call it. A void with nothing in front is private too.

public class Player : MonoBehaviour
{
    private void Heal()
    {
        health = 100;
    }

    void Start()
    {
        Heal();
    }
}

Any other script that tries to call Heal() gets an error.

Protected voids

Like private, but scripts that inherit from this one can use it too.

public class Enemy : MonoBehaviour
{
    protected void Die()
    {
        Destroy(gameObject);
    }
}

public class Zombie : Enemy
{
    void Start()
    {
        Die();
    }
}

Zombie can call Die() because it inherits from Enemy. Other scripts can't.

Public voids

Any script can call it, but it needs a reference to the object. One easy way is an Instance.

public class GameManager : MonoBehaviour
{
    public static GameManager Instance;

    void Awake()
    {
        Instance = this;
    }

    public void AddCoin()
    {
        coins++;
    }
}

public class Coin : MonoBehaviour
{
    void OnTriggerEnter(Collider other)
    {
        GameManager.Instance.AddCoin();
    }
}

This only works if there's one GameManager in the scene. You can also drag the object into a public variable in the inspector instead.

Static voids

You don't need an object at all. Call it with the class name from any script.

public class Score : MonoBehaviour
{
    public static int total;
    public int notStatic;

    public static void AddPoints(int amount)
    {
        total += amount;
    }
}

Score.AddPoints(5);

The catch: a static void can only use static variables. Using notStatic inside AddPoints gives an error.

Unity voids

Unity calls these on its own. You just write them.

VoidWhen it runs
Awake()first, as soon as the object loads
Start()once, right before the first frame
Update()every frame
LateUpdate()every frame, after all Updates are done
FixedUpdate()on a fixed timer, for physics
void Awake()
{
    rb = GetComponent<Rigidbody>();
}

void Update()
{
    if (Input.GetKeyDown(KeyCode.Space))
    {
        jumpPressed = true;
    }
}

void FixedUpdate()
{
    if (jumpPressed)
    {
        rb.AddForce(Vector3.up * jumpPower);
        jumpPressed = false;
    }
}

void LateUpdate()
{
    cam.position = player.position + offset;
}
  • Use Awake to grab components, Start for everything else that sets up
  • Check input in Update, move physics stuff in FixedUpdate
  • Cameras that follow the player go in LateUpdate so they don't jitter

Triggers

Runs when something touches a collider with Is Trigger on.

void OnTriggerEnter(Collider other)
{
    if (other.CompareTag("Player"))
    {
        coins++;
    }
}

Common mistakes

  • Missing ; at the end of a line
  • Using = instead of == in an if
  • Class name not matching the file name
  • Forgetting the f on floats
  • Missing { or }

Definitions

What all the coding words mean. Search for one or scroll through.

Nothing found.

Animator

The component that plays animations and switches between them.

Array

A list with a set size. Starts counting at 0.

int[] scores = new int[5];

Awake

Unity void that runs first, as soon as the object loads. Good for GetComponent.

AudioSource

The component that plays sounds.

audioSource.Play();

Bool

A variable that's only true or false.

bool isGrounded = true;

Break

Stops a loop or ends a case in a switch.

Canvas

Holds all your UI like buttons, text and images.

Clamp

Keeps a number between a min and max.

health = Mathf.Clamp(health, 0, 100);

Class

The main container of a script. Your variables and voids go inside it.

Collider

The invisible shape that lets objects hit each other.

Component

Anything added to a GameObject, like a Rigidbody, Collider or your own script.

Coroutine

A void that can wait before doing the next thing.

yield return new WaitForSeconds(2f);

Debug.Log

Prints a message to the console. Best way to check if code is running.

Debug.Log("it works");

Destroy

Deletes an object from the scene.

Destroy(gameObject);

Double

A decimal number with more precision than a float. Uses more memory.

double money = 10.5;

Enum

A list of named options you pick from.

enum State { Idle, Run, Jump }

Float

A decimal number. Needs an f at the end.

float speed = 5.5f;

For loop

Repeats code a set number of times.

for (int i = 0; i < 10; i++) { }

Foreach

Runs code once for every item in a list or array.

foreach (GameObject e in enemies) { }

FixedUpdate

Unity void that runs on a fixed timer. Use it for physics.

GameObject

Any object in your scene. Everything in the Hierarchy is one.

GetComponent

Grabs a component from an object so you can use it in code.

rb = GetComponent<Rigidbody>();

Hierarchy

The window that lists every object in your scene.

If statement

Only runs code if something is true.

if (health <= 0) { Die(); }

Inheritance

When a class takes everything from another class and adds its own stuff.

class Zombie : Enemy

Input

Checks keys, mouse and buttons.

Input.GetKeyDown(KeyCode.E)

Inspector

The window that shows an object's components and public variables.

Instance

A static reference to a script so other scripts can reach it easily.

GameManager.Instance.AddCoin();

Instantiate

Spawns a copy of an object or prefab.

Instantiate(bullet, firePoint.position, firePoint.rotation);

Int

A whole number with no decimals.

int coins = 10;

Invoke

Calls a void after a delay.

Invoke("Respawn", 3f);

Layer

A group you put objects in so raycasts, cameras and physics can ignore or only hit certain ones.

LateUpdate

Unity void that runs every frame after all Updates. Good for cameras.

Lerp

Smoothly moves between two values. The last number is how far between them, from 0 to 1.

transform.position = Vector3.Lerp(a, b, 0.5f);

List

Like an array but you can add and remove items.

List<string> names = new List<string>();

MonoBehaviour

What your scripts inherit from so they can go on objects and use Start and Update.

Null

Means nothing is there. The variable isn't set to anything.

NullReferenceException

The most common error. You tried to use something that's null, usually a variable you forgot to set.

OnCollisionEnter

Unity void that runs when two solid colliders hit.

OnTriggerEnter

Unity void that runs when something enters a trigger collider.

PhotonView

The Photon component that syncs an object across the network.

Prefab

A saved object you can reuse and spawn as many times as you want.

Private

Only the same script can use it.

Protected

The same script and scripts that inherit from it can use it.

Public

Any script can use it, and it shows in the inspector.

Quaternion

How Unity stores rotation. Use Euler to work with normal angles.

Quaternion.Euler(0, 90, 0)

Raycast

Shoots an invisible line and tells you what it hits. Used for guns, ground checks and pointing.

Physics.Raycast(origin, direction, out RaycastHit hit, 100f)

Return

Ends a void and can send a value back.

return health;

Rigidbody

Gives an object physics like gravity and forces.

rb.AddForce(Vector3.up * 5f);

RPC

A Photon call that runs a void on every player's game.

photonView.RPC("Jump", RpcTarget.All);

Scene

A level or menu. Your game is made of scenes.

SceneManager.LoadScene("Lobby");

ScriptableObject

A data file you make from a script. Good for items, weapons and settings.

SerializeField

Shows a private variable in the inspector.

[SerializeField] private int ammo;

SetActive

Turns an object on or off.

menu.SetActive(false);

Slerp

Like Lerp but for rotations or directions. Moves along a curve.

Quaternion.Slerp(a, b, t)

Start

Unity void that runs once before the first frame.

Static

Belongs to the class, not an object. Call it with the class name.

Score.AddPoints(5);

String

Text. Always goes in quotes.

string name = "Myers";

Switch

Runs different code depending on a value. Cleaner than lots of ifs.

Tag

A name you give objects so code can tell what they are.

other.CompareTag("Player")

Time.deltaTime

Time since the last frame. Multiply by it so movement is the same on every FPS.

speed * Time.deltaTime

Time.timeScale

How fast the game runs. 0 pauses, 1 is normal.

Time.timeScale = 0f;

Transform

An object's position, rotation and scale.

transform.position

Trigger

A collider with Is Trigger on. Things pass through it but it still detects them.

Update

Unity void that runs every frame.

Using

The lines at the top of a script that let you use a library, like a plugin.

using UnityEngine;

Variable

Holds a value you can use and change, like a number or text.

Vector3

Three numbers: x, y and z. Used for positions, directions and scale.

new Vector3(0, 1, 0)

Void

A block of code you can call by name. Also called a function or method.

While loop

Keeps repeating while something is true. Careful, it can freeze Unity if it never stops.
