# myerscs.lol

My personal website, live at https://myerscs.lol. Plain HTML, CSS and JavaScript, no build step.

- `index.html`: home page
- `about.html`: about me
- `projects.html`: projects, loaded live from GitHub
- `guide.html`: coding guide and C# plugin list
- `main.js`: navbar, footer, icons and project loading (edit your name and links at the top)
- `style.css`: all styling
- `banner.png`: the banner on the Discord card

Hosted on Vercel. Every push to `main` deploys automatically.
